## Mis historias de usuario

> Entre 5 y 7 historias en formato "como [rol] quiero [acción] para [beneficio]", pensadas desde distintos roles o necesidades del producto que el equipo está diseñando. Si escribes menos de 7, borra las líneas que no uses (mínimo 5).

1. Como **juez** quiero comprobar por mí mismo, sin depender de las partes, que el archivo presentado es idéntico al que se recolectó al inicio para decidir con confianza si la prueba es válida.
2. Como **perito recolector** quiero dejar registrado el archivo en el momento de la recolección para que después se pueda demostrar que no ha cambiado desde el origen.
3. Como **defensa** quiero verificar de forma independiente que el archivo recibido no fue alterado para aceptar o cuestionar la prueba con fundamento.
4. Como **custodio** quiero registrar cada entrega y recepción del archivo con fecha y responsable para que quede claro quién lo tuvo en cada momento.
5. Como **analista forense** quiero confirmar que el archivo que recibo es idéntico al recolectado antes de analizarlo para que mis conclusiones no sean desestimadas por dudas sobre el original.
6. Como **fiscalía** quiero ver el historial completo de quién tuvo el archivo y cuándo para presentar la prueba con una cadena de custodia sin vacíos.
7. Como **perito recolector** quiero recibir un comprobante de que mi registro quedó hecho para tener respaldo de mi trabajo si luego se cuestiona.
